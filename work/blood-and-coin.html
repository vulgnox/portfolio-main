01OVERVIEW

THE
BRIEF

Blood & Coin runs a living fantasy RP economy inside a Discord server — Coin and Blood as currencies, factions at war, and a city of Valdris that issues edicts whether or not anyone is watching.

The daily decree

Every morning at 9 AM IST an AI-generated event posts to #daily-decree. React with /decree respond, earn 50 Coin. The leaderboard in #leaderboard updates live after every action.

AI-narrated violence

/duel @user — a Llama 3.3 70B model narrates the fight, the winner takes 50 Coin. /legend turns a player's submitted moment into Hall of Legends lore. The model isn't a chatbot here; it's the dungeon master writing the server's history.

Economy guardrails

/give moves Coin between players; admin-only /forcepost and /addcoin work the levers. Three channels — daily-decree, leaderboard, hall-of-legends — and a Railway deployment with every token in environment variables.

02SYSTEM

HOW IT
WORKS

  1. Create

    Discord application with Server Members and Message Content intents; invite with embed permissions.

  2. Channel

    daily-decree, leaderboard, hall-of-legends — names must match, or override them in env.

  3. Deploy

    Railway: deploy from GitHub, pour tokens into variables, set the start command.

  4. Loop

    9 AM IST decree → /decree respond pays 50 → duels narrate → legends write lore → leaderboard updates live.

  5. Govern

    Admin commands /forcepost and /addcoin steer the economy without touching code.
