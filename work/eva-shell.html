01OVERVIEW

THE
BRIEF

eva-shell is a complete desktop replacement, not a rice. A three-column HUD — 280px flanks around a dynamic center — a 96px four-cell bottom panel, and a 16px NERV top bar carrying a live timestamp.

MAGI, rendered

Three hexagon units — MELCHIOR, BALTHASAR, CASPAR — carry live system metrics as progress bars and consensus indicators. Logs, process trees and network intercept (RX/TX) stream from /proc, /sys and journalctl through ten-plus bash helpers.

Melchior speaks

The workspace switcher doubles as an analysis console: Ollama runs llama3.2:1b locally and answers with tactical system assessments. No cloud, no telemetry — the machine interrogating itself.

One file, one mood

themes/eva-01/colors.conf controls the entire visual identity. GTK3-compatible SCSS, flat CSS, exact color match to the HTML reference — and the full stack settles at ~250MB on an i5.

02SYSTEM

HOW IT
WORKS

  1. Install

    install.sh takes the apt dependencies, builds eww from source and symlinks ~/.config/eva-shell from the repo.

  2. Compose

    i3-gaps + picom: sharp windows, desaturated blur and shadow, a custom animation curve.

  3. Stream

    Ten-plus bash helpers pull from /proc, /sys and journalctl into the panels — logs, process tree, network bars.

  4. Consult

    MELCHIOR's box runs llama3.2:1b through Ollama for local system analysis on demand.

  5. Re-skin

    One colors.conf re-themes the whole desktop; GTK3-compatible SCSS keeps it flat and fast.
