01OVERVIEW

THE
BRIEF

NOX is a free local agent for desktop automation. Mistral 7B runs through Ollama on localhost:11434 — no cloud, no API costs, all on-device, inside a Python event loop you can read in one sitting.

Fast path first

Pattern matching answers instantly: list files becomes ls -la, check disk space becomes df -h, plus memory usage, system info, processes — without waking the model at all. Only what the patterns miss goes to Mistral, and what comes back is validated strictly before anything executes. Dangerous commands never auto-run.

It remembers

“Remember that I like Python” writes to a SQLite database; every later answer is built with those facts as context — “based on the fact that you prefer Python…”. forget, list memories, clear memories — all first-class commands.

And it listens

Speech-to-text with wake-word detection — any phrase containing “nox” arms voice mode. No voice output: pyttsx3 wasn't good enough to ship.

02SYSTEM

HOW IT
WORKS

  1. Listen

    Text or voice; wake-word detection arms a voice session on any phrase containing nox.

  2. Match

    command_patterns.py recognises system and file operations and executes them instantly — no model involved.

  3. Consult

    Only unmatched input reaches Mistral through Ollama, with saved memories injected as context.

  4. Validate

    executor.py runs model-suggested commands through a safety gate — nothing dangerous executes on its own.

  5. Remember

    Anything prefaced “remember that” lands in SQLite and shapes every future answer.
