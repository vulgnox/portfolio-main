01OVERVIEW

THE
BRIEF

Outgrow is what growth_tracker grew into: a multiplayer discipline engine for exam season. Python standard library only, SQLite on disk, mobile-first web UI — ./run.sh and it's on localhost:8765 with the LAN address printed.

Crews, not accounts

First boot creates the crew NervHQ and prints an invite code. Friends open the ./share.sh public HTTPS link, enter the code, add the app to their home screen. Crew room chat plus private DMs — text only, 1000 chars, because files are a rabbit hole.

A day that ends at 3 AM

The day rolls over at 3 AM in the server's timezone — late sessions still count. Badges, level-ups, streaks and comebacks echo to Discord through an optional webhook. Admins get a dashboard: stats, DB backup download, PIN reset.

Season 0

The original growth_tracker CSV imports as Season 0 — old usernames keep their history and gain a veteran badge. Around ~80 API checks run against a temp database on their own port before anything ships. Data lives in one file: copy outgrow.db to back up.

02SYSTEM

HOW IT
WORKS

  1. Run

    ./run.sh starts the server and prints the LAN address; first boot creates the crew and its invite code.

  2. Invite

    ./share.sh prints a public HTTPS link for friends off your Wi-Fi — add to home screen, install as an app.

  3. Compete

    Log sessions, keep streaks, climb XP — badges and level-ups post to Discord via webhook.

  4. Administer

    OUTGROW_ADMINS grants a dashboard: server stats, database backup download, PIN reset.

  5. Verify

    python3 test_api.py runs ~80 checks against a temporary database on its own port.
