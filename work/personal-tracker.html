01OVERVIEW

THE
BRIEF

A mobile-first tracker for JEE Mains aspirants: log study hours per subject — Physics, Chemistry, Maths — against a daily goal, watch the streak count, keep going.

The pomodoro is the product

45-minute focus blocks, 10-minute breaks, an animated circular countdown that switches phases by itself. Focus mode strips the screen to the timer and your current task, rotates JEE-specific motivational quotes, and warns before you navigate away.

Guarded time

A screen-time controller tracks time spent in the app and enforces a configurable daily limit. Notifications-API reminders — custom label, time, day-of-week — plus a daily check-in nudge if no session has been logged.

Everything local

One index.html holds the app — HTML, CSS, JS, no framework. Chart.js draws the weekly bars; every byte lives in localStorage. Nothing is sent to any server.

02SYSTEM

HOW IT
WORKS

  1. Log

    Subject-wise hours against a daily goal; a 7-day history and a streak counter keep the pressure honest.

  2. Focus

    45/10 pomodoro with auto phase switching; focus mode hides everything but the timer and the task.

  3. Guard

    Screen-time limit with warning alerts; reminders through the browser Notifications API.

  4. Review

    Dashboard: today's hours, streak, weekly total, goal progress, per-subject bars, weekly Chart.js chart.

  5. Ship

    Vite for dev and deploy — pnpm --filter @workspace/jee-tracker run dev.

03BUILD LOG

THE
RECORD

  • Single file

    The whole app — HTML, CSS, JS — lives in index.html. No framework, no runtime build step.

  • Offline by design

    localStorage only: streaks, sessions, settings. Clear the browser and it resets — by design.

  • Vite wrapper

    A minimal Vite entry point gives dev server and deployment without touching the app itself.
