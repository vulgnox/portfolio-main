01OVERVIEW

THE
BRIEF

PSYCHE maps a friend group's personalities, scores compatibility trait by trait, and writes the analysis nobody in the group wants to write themselves. Add anyone with their MBTI type, A/T variant and five-dimension trait scores — the app takes it from there.

Four surfaces

Profile builder for everyone in the group. Head-to-head compare — compatibility per trait, plus AI analysis in four parts: synergy, clash, dynamic, verdict. Group analysis — a pairwise grid across everyone, then the group dynamic written out. Role suggestions — pick a subset and a context (startup, study group, project) and the model assigns ideal roles.

Two models, one protocol

A 70B conversational model conducts the typing session; an 8B analyzer reads the transcript across a four-phase protocol and returns the verdict. NVIDIA NIM runs both heavy ends, Groq handles the instant passes. One schema serves SQLite and Postgres alike — swap DATABASE_URL and the schema creates itself on boot.

Profiles are private by default; two users who connect by username can see each other. Deployed from render.yaml as a Blueprint — the repo's /api/health reports which storage backend is live.

02SYSTEM

HOW IT
WORKS

  1. Capture

    MBTI type, A/T variant and five trait percentages — entered straight from the 16personalities result page.

  2. Score

    Pairwise compatibility computed per trait — a grid for the whole group, never a single vague number.

  3. Analyze

    The conversational model talks; the analyzer reads the transcript across four phases and returns synergy, clash, dynamic and verdict.

  4. Assign

    Pick any subset plus a context — startup, study group, project — and the model proposes who does what.

  5. Ship

    render.yaml deploys it free; DATABASE_URL turns Render's ephemeral disk into persistent Postgres.
